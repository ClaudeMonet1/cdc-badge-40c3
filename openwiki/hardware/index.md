# Files

- [CDC Badge hardware overview](board-overview.md) - Board-level map of the CDC Badge (riatlabs/cdc-badge KiCad project) — ESP32-S3-WROOM-1, GDEY029T94-FL03 e-paper with frontlight, TROPIC01 secure element, TCA9535 keypad expander, BQ25895 power path, expansion ports, revisions and power budget.
- [E-paper display and graphics stack](display-and-graphics.md) - The GDEY029T94-FL03 296x128 monochrome e-paper (SSD1680) and frontlight, how the vendor firmware drives it with GxEPD2 + Adafruit GFX, how cdc-badge-os drives it with CalEPD and a PARTIAL→FAST→FULL refresh escalation, and what that means for plugin rendering.
- [Keypad and TCA9535 I/O expander](keypad-and-io-expander.md) - How the CDC Badge's 12-button keypad is wired through a TCA9535 I²C expander, how the vendor firmware (robtillaart TCA9555 library) and cdc-badge-os (TCA9535Keypad task) read it, and how key input reaches sandboxed plugins via polling or events.
- [Pin map, I2C and SPI buses](pin-map-and-buses.md) - Consolidated ESP32-S3 GPIO map of the CDC Badge traced from the KiCad schematic and cross-checked against cdc-badge-os hw_config.h, the plugin GPIO policy and the vendor nametag firmware, including bus topology, Raspberry Pi header routing and known disagreements.
- [Power, charging and sleep](power-and-charging.md) - BQ25895 charger and power path on the CDC Badge, the vendor firmware checklist every boot must satisfy, how cdc-badge-os and the vendor nametag firmware implement it, the light/deep/ship sleep modes, and the battery and sleep-inhibit host functions available to plugins.
- [TROPIC01 secure element, PIN and attestation](secure-element.md) - How the CDC Badge uses the TROPIC01 secure element — SPI and libtropic integration, pairing keys and secure sessions, the ECC and R-Memory slot map, PIN hashing, lockout, attestation-signed PIN record and duress PIN in cdc-badge-os, the libtropic-arduino API used by the vendor, and the named-slot secure-element host API offered to plugins.
